# Mandatory Adversarial Review (MAR) — промт для консилиума моделей

Дата: 2026-09-21. Статус: обязательный этап по DEC-0027 п.3; выполняется в конце
полного цикла согласованных работ (план `docs/roadmap/15_POST_DEC0024_PLAN_2026-09-21.md`,
W1–W4; этап C заморожен DEC-0026), **до приёмки результата владельцем**.
Владелец MAR: рецензент цикла DeepSeek. Исполнитель цикла: Gemini.
Цель: не подтвердить работу, а попытаться её сломать — найти дефекты,
недоказанные утверждения, противоречия DEC и слепые зоны рецензента.

## 1. Состав консилиума

Каждый участник судит независимо, по одному и тому же пакету артефактов.
Модель-исполнитель цикла (`gemini-3.8-flash-high`) в консилиум не входит.

| Роль | Модель (agy --model) | Обоснование |
| --- | --- | --- |
| Судья A | `claude-opus-4-6-thinking` | другое семейство, глубокая проверка кода |
| Судья B | `gpt-oss-120b-medium` | третье семейство, свежий взгляд |
| Судья C | `gemini-3.7-flash-high` | другое поколение Gemini, не исполнитель |
| Фасилитатор | DeepSeek (эта сессия) | подаёт артефакты и свои verdict, не выносит финального решения |

Минимум для действительности MAR — три судьи из разных семейств.

## 3. Промт для каждого судьи (передаётся целиком)

```text
Ты — независимый враждебный судья Mandatory Adversarial Review (MAR) проекта
Lumina Blocks (D:\Block-Puzzle). Ты не участвовал в выполнении цикла. Твоя
задача — не подтвердить работу, а сломать её: найти дефекты, недоказанные
утверждения, противоречия решениям DEC, слепые зоны рецензента и тесты,
которые проходят на сломанной реализации.

ПРОЧИТАЙ (только чтение, ничего в репозитории не меняй):
- .ai/DECISIONS.md (DEC-0008, 0012, 0016, 0018, 0024, 0025, 0026, 0027)
- docs/roadmap/15_POST_DEC0024_PLAN_2026-09-21.md
- docs/design/04_DEC0024_ACCEPTANCE_CRITERIA.md (все критерии цикла)
- docs/design/14_DEC0024_STEPS_1K_7_3_4C_REVIEW.md
- docs/audit/06_FULL_REPO_AUDIT_2026-09-20.md
- docs/audit/07_CLAUDE_FULL_REPO_AUDIT_2026-09-20.md
- docs/audit/08_GEMINI_FULL_REPO_AUDIT_2026-09-21.md
- docs/audit/09_ADVERSARIAL_REVIEW_06_07_08_2026-09-21.md
- .ai/runtime/mar/cycle-report.md (отчёт о цикле)
- изменённые файлы цикла по списку из отчёта

ПРАВИЛА:
1. Каждое утверждение — с доказательством file:line или строкой вывода команды.
2. Никаких «выглядит хорошо». Если доказательства нет — пиши «не доказано».
3. Проверь каждый критерий приёмки: PASS / FAIL / PARTIAL + доказательство.
4. Проверь тесты на поддельность: может ли тест пройти при сломанном
   поведении? Есть ли критерий, не покрытый ни одним тестом?
5. Проверь дифф на выход за скоуп (чужие файлы, лишние зависимости, скрытые
   изменения поведения).
6. Проверь противоречия с DEC: особенно DEC-0008 (только косметика),
   DEC-0012 (Google Play первый, RuStore за скоупом), DEC-0026 (монетизации
   в первом релизе нет), DEC-0024 п.7 (запрет определённых правок).
7. Атакуй и отчёт рецензента: что он пропустил или принял на веру.
8. Не переписывай DEC и не предлагай новых решений как факт — только находки.
9. Вершина враждебности — конкретика, а не тон: без оскорблений и воды.

ФОРМАТ ОТВЕТА:
A. Вердикт по каждому критерию: `критерий — PASS/FAIL/PARTIAL — file:line`.
B. Топ-5 дефектов: что, где, почему это дефект, серьёзность (P0/P1/P2),
   уверенность (высокая/средняя/низкая), чего не хватает для доказательства.
C. Тесты: какие критерии не покрыты и какие тесты ничего не доказывают.
D. Скоуп и DEC: список нарушений или «нарушений нет».
E. Три вопроса, на которые владелец должен получить ответ до приёмки.
F. Итоговый голос: ACCEPT / ACCEPT WITH CONDITIONS (список) / REJECT (причина).
   Если REJECT — минимальное условие для снятия.

Ограничение: ответ верни текстом, файлы не создавай; всё, что тебе нужно,
читается из репозитория по путям выше.
```

## 4. Запуск (PowerShell, Windows)

Подготовка (один раз): `New-Item -ItemType Directory -Force .ai/runtime/mar`.

```powershell
$mar = Get-Content -Raw -Encoding UTF8 ".ai/runtime/mar/mar-prompt.md"   # текст из раздела 3
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = New-Object System.Text.UTF8Encoding($false)

function Invoke-MarJudge([string]$Model, [string]$OutFile) {
  $mar | & "C:\Users\Dmitry\AppData\Local\agy\bin\agy.exe" `
    --model $Model --output-format json --dangerously-skip-permissions `
    > $OutFile 2> "$OutFile.err"
  $j = Get-Content -Raw $OutFile | ConvertFrom-Json
  $j.response | Set-Content -Encoding UTF8 ($OutFile -replace '\.json$', '.md')
}

Invoke-MarJudge "claude-opus-4-6-thinking" ".ai/runtime/mar/judge-a.json"
Invoke-MarJudge "gpt-oss-120b-medium"     ".ai/runtime/mar/judge-b.json"
Invoke-MarJudge "gemini-3.7-flash-high"   ".ai/runtime/mar/judge-c.json"
```

Примечания:
- Промт передаётся через stdin: PowerShell ломает аргументы с кавычками.
- `--dangerously-skip-permissions` нужен только для чтения; судьям запрещено
  менять файлы — это указано в промте.
- Для второго круга (перекрёстный допрос) тот же `agy` вызывается с
  `--conversation <id>` из JSON каждого судьи и вопросом по расхождениям:
  каждый судья видит вердикты остальных и обязан либо защитить, либо снять
  своё возражение. Расхождения, оставшиеся после этого, идут владельцу.

## 5. Правила вердикта

- **Принять:** ни одного FAIL, ни одного P0, и хотя бы два голоса ACCEPT.
- **Принять с условиями:** есть FAIL/P1 — условия фиксируются как задачи с
  критерием проверки и не закрываются без доказательства.
- **Не принимать:** любой голос REJECT или P0 — цикл возвращается исполнителю
  (Gemini) с критерием из раздела 3; рецензент проверяет исправление.
- Рецензент (DeepSeek) не может отменить голос REJECT; спор идёт владельцу.
- Вердикт MAR записывается в журнал рецензента и в отчёт о цикле; решения
  владельца оформляются как DEC, а не как текст отчёта.

## 6. Почему это обязательно

Пара «исполнитель — рецензент» замкнута: критерии, код, тесты и приборный
отчёт создаются двумя агентами одного цикла. MAR вводит третью, четвёртую и
пятую точки зрения разных семейств моделей и делает приёмку условной без них
(DEC-0027 п.3). Стоимость — три прогона `agy`; цена пропуска — систематический
дефект, принятый дважды одними и теми же глазами.
