## 2. Ключевые архитектурные вехи

1. **Развязка доменных ядер (DEC-0001)**:
   - Отказ от принудительного объединения разнородных механик (падающие фигуры тетриса, размещение блоков 8×8, свайпы match-3) в один универсальный класс.
   - Каждая игра изолирована в `lib/domain/<game>/` с собственными тестами и независимой сериализацией снапшотов.
2. **Гарантия честной монетизации (DEC-0008, DEC-0026)**:
   - Полное удаление любых pay-to-win механик, вспомогательных расходников за деньги и рекламы.
   - Подготовка под продажу только косметических палитр/тем оформления.
3. **Безопасность релизных адаптеров (DEC-0007)**:
   - Запрет компиляции и сборки с отладочными моками (`DebugIapStoreService`, `InMemoryRemoteConfigRepository`) в релизном режиме через строгие `--dart-define` флаги в GitHub Actions.
4. **Стабильность звуковой подсистемы (DEC-0028)**:
   - Равномощностной кроссфейд между треками (1.8 с), устранение спама дакинга при комбо-сериях, выделение независимых каналов под звуковые эффекты без срезания голосов.
