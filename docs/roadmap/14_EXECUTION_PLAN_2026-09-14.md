## 2. Главный вывод

Дорожная карта требовала «фундамент до контента», но пять месяцев ушли в Phase 4:
написаны Tetris и Match-3, аккуратно и с тестами. Phase 1 при этом не сдвинулась.
Итог — три хорошие игры, в которые никто не может сыграть.

DEC-0006 вернул правило в силу. Ближайшая ценность — не новый контент, а
**замкнуть несколько сквозных сценариев**: сборка, конфигурация, покупка,
восстановление партии.

## 4. Реестр техдолга

**Блокирующий:** debug-адаптеры в релизе (DEC-0007); слом Remote Config (R2);
расхождение веток; непроверенный биллинг; `main()` без ожидания `bootstrap()`.

**Высокий:** биллинговые края №10/№11 из ревью PR #42; неполные снимки партий;
отсутствие локализации; отсутствие widget/integration-тестов и
`cold_kill_recovery_test`; отсутствие `firestore.rules`.

**Средний:** три файла-гиганта, из `GameLoopController` не вынесены solver и
эмиссия аналитики; глубина Match-3 (решается по данным, DEC-0005); перф трёх
рендереров не профилирован; аудио — плейсхолдеры; музыка молчит после
возврата Tetris→Classic; настройки не доходят до открытого экрана; симуляционный
тест пишет в отслеживаемый JSON.

## 5. Риски

1. **Сведение веток** — расхождение проходит по `tetris_engine.dart`, который
   правили обе линии. Полный прогон тестов на каждом шаге слияния.
2. **Первое включение Firebase** покажет реальную частоту падений, сейчас
   неизвестную вообще.
3. **Песочница Play** обычно вскрывает расхождения по SKU и правам.
4. **Перф на низком железе** не измерен ни разу; гейт ослаблен по DEC-0014 и
   должен помечаться как ослабленный везде, где докладывается.
5. **Медиа без таймбокса** — инструментарий имеет свойство расширяться вместо
   поставки; отсюда ограничение DEC-0019.
