# Предложения по саунд-дизайну, музыке, визуалу и геймплею Lumina Blocks (2026-09-16)

## 1. Музыкальная концепция и анализ референсов (`D:\Block-Puzzle\saplesmusic`)

### 1.1. Разбор референс-треков (Parkan OST)
В папке `saplesmusic` представлены ключевые треки культовой космической серии **Parkan** (Nikita, 1997 / 2005):
1. **`Parkan 1 OST - Track 1.mp3`** (2:44, 320 kbps):
   - *Характер*: Глубокий, парящий эмбиент, медленные воздушные пэды, мерцающие колокольчики, ощущение открытого невесомого космоса.
   - *Роль в игре*: Идеально подходит для главного меню и медитативного расслабления в Classic Mode.
2. **`Parkan - Track 3.mp3`** (2:45, 256 kbps):
   - *Характер*: Гипнотический ритмичный арпеджированный синтвейв, динамичный аналоговый басовый пульс, кристально чистые клавишные риффы.
   - *Роль в игре*: Создает непрерывное состояние потока («flow state») — максимальная концентрация и залипание для быстрых режимов (Tetris / Match-3).
3. **`Parkan Хроника Империи - Track 4.mp3`** (3:44, 320 kbps):
   - *Характер*: Многослойный футуристический саундскейп, медленно эволюционирующие фильтры (filter sweeps), мистические пэды, переходящие в мягкий даунтемпо-бит.
   - *Роль в игре*: Поддерживает глубокие длительные игровые сессии (от 10 минут и дольше) без слуховой усталости.
4. **`Parkan 2 - Moon Normal.mp3`** (8:01, 320 kbps):
   - *Характер*: Монументальный, пространственный эмбиент с массивными низкочастотными дронами и аналоговой теплотой.

### 1.2. План расширения саундтрека
- **Текущее ограничение**: В игре сейчас задействован один 19.5-секундный луп (`music_loop.wav`). При непрерывной игре более 2-3 минут он начинает приедаться.
- **Предлагаемое решение**: Саундтрек из **4 полноценных треков по 2.5–4.0 минуты** (суммарно ~13 минут музыки):
  * **Трек 1: "Lumina Drift" (2m 45s)** — Невесомый космический эмбиент с кристальными колокольчиками (референс: Parkan 1 Track 1). Фоновый трек для Меню и Classic Mode.
  * **Трек 2: "Cybernetic Pulse" (3m 15s)** — Арпеджированный гипнотический синт-грув (референс: Parkan Track 3). Основной трек для Тетриса и интенсивных сессий.
  * **Трек 3: "Starlight Voyage" (3m 40s)** — Эволюционирующий медитативный саундскейп со свипами фильтров (референс: Parkan Chronicles Track 4). Трек для Match-3 и Daily Challenge.
  * **Трек 4: "Deep Nebula" (3m 30s)** — Даунтемпо с аналоговым басом и мерцанием звезд (референс: Parkan 2 Moon Normal).
- **Архитектура плеера (`MusicPlaylistManager`)**:
  * Плавный кроссфейд (3.0 сек) между треками.
  * Режим Shuffle / Repeat.
  * Возможность переключения трека или выбора любимой темы в Настройках.

## 2. Саунд-дизайн и «сочность» (Juiciness Audio Overhaul)

Чтобы сделать игру по-настоящему залипательной («как лопание пупырчатой пленки»), звуковой ландшафт должен давать богатый физический и гармонический отклик:

1. **Гармоническая лесенка комбо (Harmonic Pentatonic Scale)**:
   - При последовательных очистках линий подряд звук комбо повышается по пентатонической шкале (C4 -> D4 -> E4 -> G4 -> A4 -> C5 -> D5).
   - *Эффект*: Игрок ощущает, что комбо «играет гармоничную мелодию». Это вызывает мощный дофаминовый отклик.
2. **Саб-басовый тактильный щелчок (Sub-bass placement thud)**:
   - В текущей версии звук `piece_placed.wav` легкий.
   - Предлагается: Добавить низкочастотный «бархатный» тычок (~85-110 Гц, затухание 70 мс) с синхронным виброоткликом `HapticsFeedback.selectionClick()`. Блоки начинают ощущаться весомыми, как гладкий тяжелый хрусталь.
3. **Градация очистки линий (Multi-line Crescendo)**:
   - 1 линия: Чистый хрустальный звон + мягкий рассеянный воздух.
   - 2 линии (Double): Двойной аккорд + нарастающий сустейн.
   - 3 линии (Triple): Звенящий хрустальный разрыв + плотный саб-всплеск.
   - 4 линии (Tetris / Mega Clear): Космический резонирующий взрыв с широким стерео-хвостом.
4. **Специальный саунд-пак для Match-3**:
   - «Клик» кристалла при касании (хрустальная грань).
   - Мягкий шелестящий «свист» при свайпе.
   - Пружинящий резиновый звук отказа («тук-тук») при недопустимом ходе вместо беззвучия.
   - Восходящая модуляция звука на каждый каскад (+1 полутон за каждый виток каскада).
5. **Тетрис-эффекты**:
   - Механический четкий щелчок на поворот фигуры (Rotation Tick).
   - Массивный удар с легким басовым эхом на Hard Drop.
   - Свистящий переход на Hold.

## 3. Визуальный экшен и анимационный сок (Visual Juice)

1. **Неоновая ударная волна (Shockwave Ripple)**:
   - В момент сборки линии или комбо от очищенного ряда по всей сетке расходится полупрозрачная круговая ударная волна (радиальное искажение/свечение), заставляя соседние ячейки кратковременно ярко вспыхнуть.
2. **Всплывающие летающие цифры и бейджи (Floating Action Text)**:
   - В месте очистки всплывают анимированные золотисто-неоновые цифры: `+120`, `+350`, а при комбо — динамические плашки: `COMBO x2!`, `GREAT!`, `COSMIC!`, плавно улетающие вверх с затуханием.
3. **Проекция привязки (Snap Ghost Projection) в Classic Mode**:
   - При перетаскивании фигуры на доску отображать мягкий пульсирующий контур ячеек (Ghost Silhouette) прямо под будущим местом посадки.
4. **Микро-тряска камеры (Juicy Screen Shake)**:
   - На мощных ходах (Hard Drop в Тетрисе, очистка от 2 линий, каскады Match-3) добавляется импульс камеры на 2-4 пикселя на 80 мс. В Настройках предусмотрен ползунок интенсивности или тумблер включения/выключения для чувствительных игроков.
5. **Улучшенные физические частицы (Glass Shard Burst)**:
   - При разбивании блоков генерируются светящиеся осколки с легкой симуляцией гравитации и затухающим неоновым шлейфом.
6. **Живой космический фон на Главном экране**:
   - Медленное «дыхание» туманности (Nebula Drift) и медленно покачивающийся объемный стеклянный кристалл в центральной карточке меню.

## 4. Геймплейные наблюдения и улучшения по итогам 2–3 минут в каждой игре

### 4.1. Classic Mode
1. **Динамический центр хвата (Adaptive Drag Anchor)**: точка захвата автоматически центрируется относительно формы фигуры, либо поддерживается визуальный проекционный луч.
2. **Честный рандомизатор (Fair Bag Randomizer)**: в каждом триплете выдаваемых фигур гарантированно должна быть как минимум одна фигура, которую математически можно разместить на текущей доске.
3. **Дополнительные бустеры**: помимо Hint и Undo добавить бустер «Reroll» (перебросить лоток фигур) и «Молот» (разбить 1 мешающую клетку).

### 4.2. Tetris Mode
1. **Альтернатива жестами (Gesture Swipes)**: в Настройках добавить переключатель «Кнопки / Свайпы» (свайп влево/вправо — перемещение, тап — поворот, свайп вниз — мягкое падение, резкий свайп вниз — Hard Drop).
2. **Задержка фиксации (Lock Delay 0.5s)**: при соприкосновении с полом давать игроку полсекунды на подворот фигуры (T-spin / slide).
3. **DAS / ARR (Auto-repeat)**: при зажатии стрелок влево/вправо фигура должна плавно и быстро скользить к стенке.

### 4.3. Match-3 Mode
1. **Визуальные спец-кристаллы (Special Gems)**:
   - 4 в ряд: Кристалл со светящейся полосой (Laser Gem) — при взрыве очищает всю вертикаль или горизонталь.
   - 5 в ряд: Космическая призма (Cosmic Prism) — при свайпе уничтожает все кристаллы выбранного цвета на поле.
   - T/L форма: Кристальная бомба (Bomb Gem) — взрыв 3x3.
2. **Подсказка при бездействии (Idle Hint)**: если игрок не делает ход более 4 секунд, мягко пульсировать доступную для свайпа пару кристаллов.
3. **Каскадный множитель**: множитель очков x1.5 за каждый дополнительный уровень цепной реакции с отображением плашки `CASCADE x2!`.
