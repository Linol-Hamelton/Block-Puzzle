## 2. Состав спринта реализации (G1) — строгий порядок

**Этап A. Предусловия (без них дальше нельзя):**
1. Расширение бенчмарка Step 6+ (сценарии: тройной клир с частицами/волной, reduced motion on/off; p50/p95; джанк-лог 20 мин).
2. Телеметрия: `undo_used`, `near_record`, `clear_size`, `game_over_fill_ratio`, `all_clear`, `reduced_motion_toggled`, `danger_pulse_shown`.

**Этап B. Аудио и UX (низкий риск):**
3. Аудио-баланс + слайдеры (музыка 0.50; line_clear 0.42/0.50; combo 0.48/0.58; `piece_placed` 0.75→0.35; дебаунс 50 мс).
4. Проводка треков по режимам (menu/classic/tetris/match3).
5. Coalescing дакинга 100–120 мс, глубина −1.5 дБ, восстановление 250 мс.
6. Изотропный screen shake 2–4 px / 80 мс.
7. Разделение таймингов попапов (0.8–0.9 с).
8. Честный New Best + «почти рекорд» + Lines Cleared / Max Combo.
9. Бесплатный Undo + `hasUsedFreeUndo` (дефолт false) + сброс комбо.
10. Неблокирующий AudioFocus (`gainTransientMayDuck`).
11. Хаптика: light 1–2 / medium 3–5 / heavy 6+, All Clear — двойной heavy.
12. Reduced Motion (тряска 0, вспышка 25%, пульсация off).
13. Drop ASMR: питч ±4% или два сэмпла (с проверкой `playbackRate`).
14. KEEP_SCREEN_ON + подтверждение выхода из партии.
15. Контекстный совет после первого Game Over (один раз).

**Этап C. Контент/визуал (после гейта бенчмарка):**
16. Anti-chunking + симуляции 5000 раздач (стенд `internal_playtest`).
17. Danger Edge Pulse (fill>75%, альфа 0.15–0.25, off при Reduced Motion).
18. All Clear празднование (без очков).
19. Вербальные тиры в центрированном HUD (l10n).
20. Throttle Guard: одна центроидная волна.
21. Частицы 3→6/ячейку + пул (значение пула — по замеру; гейт p50 ≤26.1 мс).
22. Палитры: контраст-аудит (дейтеранопия) + селектор 3 тем бесплатно.

**Вне спринта:** новые режимы, соцфункции, валюта, рампа сложности, Fever, Layered Stems, Placement Preview (v1.1), скрытая pity.

## 3. Гейты приёмки

- `flutter analyze` — 0; `flutter test` — 395/395 + новые тесты: duck-пол ≥0.70 при 4 событиях за 50 мс; round-trip `GameSnapshot` с новыми полями; дебаунс слайдеров; anti-chunking симуляции (0 мгновенных дедлоков на 5000 забитых раздач; средний счёт симуляции не вырос).
- Step 6+ на Xiaomi 2209116AG: p50 растра ≤26.1 мс на тройном клире; 20 мин без джанка; откат плотности частиц при спайке.
- Ручные проверки: аудио в наушниках/динамике; Spotify не на паузе; Undo не обнуляется после рестарта; «почти рекорд»/бейдж честные; экран не гаснет; выход из партии спрашивает подтверждение.
- Соответствие DEC: монетизационные поверхности скрыты; офлайн-прогон в авиарежиме.

## 4. Процесс

- Реализация: Gemini (agy CLI) в выделенном worktree; без коммитов и пушей до команды владельца.
- Ревью: DeepSeek отдельным спринтом (adversarial review дифа, независимый прогон тестов/бенчмарка, сверка с DEC-0028).
- Старт: по явной команде владельца (DEC-0027 п.1).
