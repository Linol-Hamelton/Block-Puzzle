# Консолидированная оценка v3: три отчёта, проверка недоказуемого, уточнённый топ-20

Дата: 2026-09-21. Источники: `01_GAMEPLAY_TOP20_2026-09-21.md` (наш консенсус), `02_GAMEPLAY_INDEPENDENT_EVALUATION.md` (Claude/Antigravity), `opinion-2.md` (внешний отчёт №3), обсуждение с Gemini (раунд R3, `.ai/runtime/lumina-research/g-r3.md`), прямая проверка кода DeepSeek.
Вердикт: наше предложение **улучшается точечно** — 5 содержательных правок приняты; большая часть отчёта 03 (проценты, режимы, валюта, соцфункции, рамп сложности) отклонена по DEC/доказательствам; 4 утверждения Claude подтверждены кодом, 3 — недоказуемы и удалены.

## 1. Что улучшено в нашем топ-20 (было → стало)

1. **Аудио-баланс (№1).** Стало: дополнительно снизить `piece_placed` 0.75→0.35 (`flame_game_sfx_player.dart:190`). Доказательство: каждый дроп громче музыки (0.32) более чем вдвое — это и есть «метроном» из жалоб. Остальные уровни без изменений (музыка 0.50; line_clear 0.42/0.50; combo 0.48/0.58).
2. **Дакинг (№3).** Формулировка исправлена: `duck()` не суммирует децибелы (`_duckMultiplier = factor` идемпотентен), но **перезапускает таймер 150 мс** (`music_playlist_manager.dart:347-366`) — серия комбо продлевает приглушение и вызывает частые `setVolume` («залипание» и дрожание громкости). Стало: coalescing-окно 100–120 мс (один вызов duck на пару line_clear+combo), глубина −1.5 дБ, восстановление 250 мс.
3. **Хаптика (№9).** Стало: точные пороги — комбо 1–2 `light`, 3–5 `medium`, 6+ `heavy`, All Clear — двойной `heavy` (80 мс).
4. **Danger Edge Pulse (№11).** Стало: мягкая янтарно-красная пульсация контура при fill>75%, альфа 0.15–0.25, цикл 1.5 с; отключается тумблером Reduced Motion (уточнение Claude).
5. **Защита партии (№19–20).** Стало: подтверждение выхода из незавершённой партии оставлено в топ-20; `KEEP_SCREEN_ON` — отдельным пунктом; контраст пустых ячеек (12–15%) перенесён в блок палитры/Волну 2, чтобы не смешивать с защитой сессии.
6. **Undo (№7).** Добавлено доказательство актуальности: кнопка уже упирается в `insufficient_tools_credits` (`game_loop_controller.dart:722`), т.е. механика реально заблокирована, а не гипотетична.

## 3. Отклонено из отчёта 03 (opinion-2) с причинами

| Пункт 03 | Решение | Причина |
| :--- | :--- | :--- |
| Проценты частот (92/87/90/85/78…) | Отклонить как доказательство | Метод выборки и размеры когорт не указаны; числа недоказуемы. В нашем отчёте частоты помечены базами (DS — проверенные источники, G — экспертная оценка). |
| Динамическая сложность (рампа по времени) | Отклонить | Главный триггер отзывов «rigged RNG» (10/24 DS; 39/45 G). В коде уже есть адаптивные веса (`basic_difficulty_tuner.dart`), искусственный рампа не нужен; вместо неё — anti-chunking и Danger Pulse. |
| Новые режимы (Time Rush / Puzzle / Endless / Zen) в v1.0 | Отложить | Режимы заморожены роадмапом; фокус — стабилизация Classic/Tetris/Match-3. |
| Социальные таблицы, вызов друзей, мультиплеер | Отклонить | Требует серверов/авторизации, ломает 100% офлайн; в отзывах лидерборды = боты. |
| Undo/Shuffle за виртуальную валюту | Отклонить | Нарушает DEC-0026 (в v1.0 нет монетизации) и DEC-0008; базовый QoL не продаём. |
| Fever Mode | Отклонить/отложить | Ломает zen-темп; Octalysis-разбор Block Blast: streak-механики дают Avoidance 9/10 («больше тревоги, чем радости»). |

| «Больше juice» без бюджета кадра | Отклонить | Кадровый лимит 26.1 мс/38 fps; принят только измеримый набор (частицы+пул, throttle, гейт Step 6+). |

Примечание: «интерактивный туториал», «контекстные подсказки», «экран итогов», «плавающие очки» — частично уже реализованы (инвентаризация), частично входят в план (№6, №17, FTUE в Волне 2). Контекстный совет при первом поражении рекомендуется добавить в Волну 2 отдельным S-пунктом (в топ-20 не входит).

## 5. Уточнённый топ-20 (v3; изменения помечены)

Волна 0 — предусловия и быстрые победы:
1. Step 6+ бенчмарк (предусловие; вне рейтинга продукта).
2. Телеметрия механик (предусловие).
3. Аудио-баланс + слайдеры — **+piece_placed 0.75→0.35**.
4. Проводка треков по режимам.
5. Дакинг: —1.5 дБ + **coalescing 100–120 мс (исправленная механика)**.
6. Изотропная тряска 2–4 px / 80 мс.
7. Разделение таймингов попапов (0.8–0.9 с при физике 3.5x).
8. Честный New Best + «почти рекорд» + Lines/Max Combo.
9. Бесплатный Undo + `hasUsedFreeUndo` (**подтверждена причина: `insufficient_tools_credits`**), комбо сбрасывается.
10. Неблокирующий AudioFocus (**без недоказуемых процентов**).

Волна 1 — ядро качества:
11. Хаптика: **пороги light 1–2 / medium 3–5 / heavy 6+, All Clear — двойной heavy**.
12. Anti-Chunking + симуляции 5000 раздач (стенд `internal_playtest`).
13. Danger Edge Pulse: **альфа 0.15–0.25, цикл 1.5 с, off при Reduced Motion**.
14. Частицы 3→6/ячейку + пул (по замеру) — только после №1.
15. Throttle Guard: одна центроидная волна (параметры — по замеру, не по декларации).
16. All Clear: празднование без изменения очков.
17. Вербальные тиры в центрированном HUD.
18. Reduced Motion (тряска 0, вспышка 25%, пульсация off).
19. Drop ASMR: питч ±4% или два сэмпла.
20. Защита партии: **подтверждение выхода + KEEP_SCREEN_ON** (контраст ячеек — в блок палитры/Волну 2).

## 6. Вопросы владельцу (итог)

1. Разделение таймингов (физика 3.5x + UI 0.8–0.9 с).
2. All Clear: праздник без очков (рекомендация) или бонус.
3. Бесплатный Undo: сбрасывать комбо (рекомендация) или сохранять.
4. Палитры: открыть бесплатно в v1.0 или придержать до этапа C (позиция Claude — открыть).
5. Anti-chunking: подтвердить, что игра не гарантирует спасение (только отсечение сдвоенных тупиков).
6. Danger Pulse: не нарушает ли дзен.
7. Скрыть монетизационные SKU до этапа C.
8. Технические предписания: дефолт `hasUsedFreeUndo=false`; троттлинг слайдеров 50 мс; центрирование плашек над доской.
